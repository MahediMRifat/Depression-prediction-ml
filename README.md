# Depression Prediction Using Machine Learning 🧠

## Overview
This repository contains the code and final report for my AI course project. The goal of this project is to predict signs of depression using Machine Learning and Natural Language Processing (NLP). 

## Models Implemented
* K-Nearest Neighbors (KNN)
* Decision Tree
* Logistic Regression
* Natural Language Processing (NLP) for text feature extraction

## Repository Contents
* `Depression_Prediction_Models.ipynb`: The Google Colab notebook containing all the Python code, data preprocessing, and model training.
* `Depression_Prediction_Report.pdf`: The detailed project report discussing methodology, model comparisons, and final results.
